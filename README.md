# NoReplyPingEnhanced

This plugin automatically disables reply pings, with additional per-server filtering and user-specific no-ping rules.

But what this plugin **will not** do is stop incoming pings from users that did not turn off the ping option. This plugin only affects the pings on replies you make.

## Installation

Copy both `NoReplyPingEnhanced.plugin.js` and `NoReplyPingEnhanced.raw.css` into your BetterDiscord plugins folder.

If the CSS file is missing, the plugin will still load, but the settings UI will fall back to reduced inline styling.
